# Adaptable visual reference library

Use `assets/library/catalog.json` for selection and `index.html` for visual comparison.
Index both relationship and spatial form. A palette does not determine the relation.

| Relationship | Resolve first | Possible expressions |
|---|---|---|
| comparison | Dimensions, asymmetry, qualifications | Paired paragraphs, matrix, annotated contrast |
| evidence | Claim supported by each source | Aligned exegesis, claim with witnesses, progressive evidence |
| foundation | Grounding vs historical realization | Linked levels, ground and unfolding, paired stages |
| sequence | Temporal order vs logical steps | Timeline, stages, progressive pages |
| causality | Whether a cause is actually asserted | Directed chain, branching outcomes, illustration |
| hierarchy | Category, rank, part-whole, priority | Tree, nested structure, grouped overview |
| correspondence | Which items match and how | Mirrored clauses, aligned pairs, verse/gloss |
| synthesis | What the audience should retain | Focused statement, integrated diagram, application |
| illustration | Whether imagery clarifies an abstraction | Literal example, qualified analogy, sourced image |

These are search aids, not an exhaustive design space. For theology, distinguish temporal
sequence from eternal grounding and personal distinction from divisions of essence.

Entries record intent, spatial form, source-page provenance, variations, caveats and evidence.
`reference` is inspiration, not endorsement of every word, font or density. Layout inspection
does not verify source quotations. The initial references come from one author-provided course;
some relationship families intentionally have no example yet. Search results are candidates,
not automatic semantic judgments.

Inspect selected previews, borrow the relational idea and recompose for the audience, wording,
language balance and style. Preserve the meaning of arrows, size, containment and order.
Imagery is allowed where useful and permitted by the project. The source series' no-imagery
choice is local, not global. Focused text pages can serve emphasis and pacing.

When no entry fits, develop a new expression and record why. Review successful variants for
inclusion; merge redundant entries. Keep known-broken pages in private issues, not exemplar
cards. A repaired variant needs its own provenance, rather than replacing the original preview.

Gallery feedback can record keep/change/reject, scope and viewing context. Export JSON and
import with `project.py feedback`. Browser-local drafts are not maintained records. Import
only appends pending observations; it never changes a default, style or pattern status.

An entry can contain multiple source examples. Switch between them or compare two side by
side; each retains its source page/hash. Feedback targets the currently selected example,
identified by its caption. Unsaved reason text stays with its example when switching within
the page. Comparison previews are source references, not newly authored/validated variants.
