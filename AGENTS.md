# Working in Ministry Tools

Start in the directory for the requested skill and follow its README. For a single-skill change, read and test that skill. When the score handoff changes, check both the translator producer and Worship Slides consumer. Keep each installable skill self-contained.

Run builds and checks from each project's directory. Keep local manuscripts, service materials, song deliveries, private feedback and build exports out of Git. Use invented or approved examples. See the root README for release tags and the historical release locations.
